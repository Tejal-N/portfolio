# Tejal N — Portfolio

My portfolio website showcasing my projects, UI/UX work, education, certifications, and experience.

Designed with a retro MS Paint / classic Windows-inspired interface while being built with a modern frontend stack.

## Live Website

https://tejal-n.vercel.app/

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Features

- Interactive desktop-style interface
- Project showcase
- UI/UX and design work
- Education and certifications
- Responsive design
- Custom animations and interactions
